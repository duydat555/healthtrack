# Mẫu biên bản Retrospective 4Ls

> Sao chép mẫu này sau mỗi Sprint/Phase. Đây là biểu mẫu trống; chỉ ghi nhận ý kiến đã được nêu trong buổi Retro.

## Thông tin buổi Retro

- **Sprint / Phase:**
- **Ngày, giờ:**
- **Địa điểm / hình thức:**
- **Người điều phối:**
- **Người ghi biên bản:**
- **Người tham dự:**
- **Mục tiêu Retro:**

## 4Ls

### Liked — Điều nhóm thích hoặc thấy hiệu quả

| Ý kiến / quan sát | Ví dụ hoặc bằng chứng (nếu có) |
|---|---|
|  |  |

### Learned — Điều nhóm đã học được

| Bài học | Tình huống liên quan |
|---|---|
|  |  |

### Lacked — Điều còn thiếu hoặc gây cản trở

| Thiếu sót / trở ngại | Ảnh hưởng |
|---|---|
|  |  |

### Longed for — Điều nhóm mong muốn có hoặc thay đổi

| Mong muốn | Kết quả kỳ vọng |
|---|---|
|  |  |

## Hành động cải tiến

| Mã | Hành động cụ thể | Ưu tiên | Người phụ trách | Hạn hoàn thành | Cách xác nhận hoàn tất | Trạng thái |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  | Chưa bắt đầu |

## Theo dõi từ Retro trước

| Hành động cũ | Kết quả / bằng chứng | Tiếp tục, điều chỉnh hay đóng |
|---|---|---|
|  |  |  |
